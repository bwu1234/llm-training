Model architecture explorer

GPT-2 and Qwen3 side by side, traced from this repository's own model code. Each row is a module that actually runs in one forward pass, in the order it runs, with its output shape and parameter count. Select a row to read what it does, its parameters and its forward source. Selecting a row also highlights the module at the same path in the other model.

ShapesB is the batch size and T the number of tokens. Every other dimension is the preset's own number.
What isn't a boxResidual additions, the head split, RoPE, causal masking and the SwiGLU multiply are plain code inside a module's forward, so they appear in its source, not as rows.
Where this comes fromEach model is built on PyTorch's meta device and traced with module hooks. Regenerate with uv run python -m llm_training.explain.
The model code is derived from Sebastian Raschka's LLMs-from-scratch (license) and reasoning-from-scratch (license), both under the Apache License 2.0. Each source excerpt shows its file's license header.
